# Arusha Wildlife Safaris — website demo

A single-page demonstration website for Arusha Wildlife Safaris, a Tanzania-based
tour operator in Arusha. Built as a self-contained `index.html`.

**Demo content.** Itineraries, prices and testimonials are sample content written to
show structure. Photography is licensed stock and Creative Commons imagery used to
represent Tanzania — it is not the operator's own. Credits are on the Demo Notes page.

Real details taken from the operator: company name, tagline, WhatsApp and phone.
